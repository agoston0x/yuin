# web

The site: the landing page today, the setup console next.

Next.js, App Router, no CSS framework — `app/globals.css` is the stylesheet the design was
drawn in, carried across unchanged. Only two things are client components: the carousel,
which holds an index, and the hero buttons, which scroll.

```bash
npm install
npm run dev     # :8750
npm run build && npm start
```

The design reference the page was built from lives outside this repo, deliberately.
